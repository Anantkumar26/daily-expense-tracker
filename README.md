# Daily-expense-tracker

## Project Objective

The main objective of this project is to help users record their daily expenses and calculate their total spending. It also provides a category-wise summary of expenses.

## Features

- Add a new expense
- View all recorded expenses
- Calculate total expenses
- View category-wise expense summary
- Simple command-line interface

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements

## Requirements

- Python 3.x
- No external libraries are required.

## How to Run

1. Install Python 3.x.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

python expense_tracker.py

## How It Works

The user selects an option from the menu and enters the required expense details. The program stores the expenses and provides options to view expenses, calculate the total amount, and see a category-wise summary.

## Expected Output

The program displays a menu through which the user can manage daily expenses and view spending information.

## Conclusion

The Daily Expense Tracker demonstrates the practical use of basic Python programming concepts and provides a simple solution for managing daily expenses.
